# Buildly Static Marketing Website Starter

## Template selection
The project uses **TemplateMo 282 Building** as the free template reference/base direction because TemplateMo states the template is free for commercial and non-commercial use.

Source:
https://templatemo.com/tm-282-building

This starter is a lightweight Buildly-specific implementation with its own content and CSS. Replace placeholder contact/domain information before production.

## Files
- index.html — Home / landing page
- how-it-works.html — Client/Contractor workflow page
- assets/css/style.css — shared styling
- assets/js/site.js — minimal JS
- robots.txt — crawl directives
- sitemap.xml — initial sitemap

## Local preview
Open `index.html` directly in a browser, or run a local web server:

python -m http.server 8080

Then open http://localhost:8080

## SEO
The HTML already contains:
- semantic headings
- unique title tags
- meta descriptions
- canonical URLs
- Open Graph metadata
- basic JSON-LD
- robots.txt
- sitemap.xml

Before launch:
1. Replace https://www.buildly.ph with the final domain.
2. Verify Google Search Console.
3. Add GA4 if desired.
4. Add a favicon and real Open Graph image.
5. Replace placeholder contact information.
6. Add Privacy Policy and Terms pages.
7. Build keyword/location content only where it provides useful unique information.
